2. Description of Service

Stepura is a mobile fitness application that provides:

  • Step counting using your device's built-in motion sensors
  • GPS workout recording (walks, runs, hikes and rides) with route maps
  • Estimated calorie burn calculations based on user-provided profile data
  • Estimated distance tracking based on stride length or GPS data
  • Monthly fitness challenges, virtual walking expeditions and collectible badges
  • Optional paid features (Stepura Pro) described in section 3
  • Streak tracking with streak freezes for maintaining consistent activity habits
  • Optional daily reminders and streak-risk notifications
  • Progress visualization through charts and statistics

The App does not require a user account. All features work offline, except map imagery, which requires an internet connection to load from Mapbox.
